2. System Components & Implementation Details

2.1 Automated Data Ingestion (generate_dataset.py)

The dataset ingestion module generates synthetic training samples representing customer behavioral telemetry: basket_volatility, stock_gap, promotion_load, and delivery_delay with a binary target label. In the Jenkins pipeline, this module ensures fresh data ingestion prior to every training cycle.

2.2 Model Training Pipeline (train.py)

The training script computes deterministic SHA256 hashes of the dataset, fits a Logistic Regression model via scikit-learn, validates accuracy against a strict threshold, bundles the model and feature schemas via joblib into artifacts/model.joblib, and records pipeline telemetry into artifacts/metrics.json.

2.4 Docker Containerization (Dockerfile)

The container image utilizes a slim base (python:3.11-slim) with minimal runtime overhead. It pre-packages FastAPI, Uvicorn, scikit-learn, joblib, and pandas, copying the validated artifacts/ and application code. Port 8000 is exposed to serve real-time inferences.

2.5 Jenkins CI/CD Pipeline (Jenkinsfile)

The declarative pipeline runs on the AWS EC2 instance under the job name MIDTERM-SP23-BAI-031:

  • Trigger: Automated GitHub push webhook (githubPush()).
  • Stage 1 (Checkout): Fetches latest commit and registers Git SHA.
  • Stage 2 (Setup Python): Creates a clean virtual environment and installs dependencies.
  • Stage 3 (Fetch Latest Data): Runs generate_dataset.py --rows 300.
  • Stage 4 (Train Model): Executes train.py and persists artifacts.
  • Stage 5 (Run Tests): Executes the 19 pytest cases. Build terminates on failure.
  • Stage 6 (Build Docker Image): Tags image as faiqster/devops-labmidterm-sp23-bai-031:latest.
  • Stage 7 (Deploy to EC2): Stops existing container, spins up the new container on port 8000, and prunes dangling images.
  • Stage 8 (Health Check): Probes http://3.110.121.46:8000/health with a 15-second grace window, verifying HTTP 200.
  • Post Actions: Dispatches build report and metrics via send_email.py to evaluator.
